# 用户自建帖子类型：通勤包里常备

计划生成：4 条。

内容方向：围绕午后工位、地铁回家或便利店顺手购买等日常场景，写一次具体但克制的饮用选择。

目标人群：规律通勤、下午容易想喝有味道饮品的普通上班族。

标题方向：具体时间或场景 + 一个小变化，不使用夸张感叹和悬念党表达。

正文结构：生活困扰开场 → 拿出饮品 → 口味与规格体验 → 有依据的产品事实 → 适合的具体场景。

语气：第一人称、自然、短段落、少感叹号，不假装长期使用或制造购买焦虑。

一定要有：青柚味；330ml；至少一个通勤或工位场景。

一定不要有：减肥；燃脂；零负担；虚构价格；未经确认的成分；对竞品的负面评价。
